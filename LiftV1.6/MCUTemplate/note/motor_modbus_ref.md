# SVD750-RS 电机 Modbus 通讯参考

> 电机地址: **0x03** | 波特率: **115200** | 数据位: **8** | 停止位: **1** | 校验: **无** | 协议: **Modbus RTU**

---

## 关键参数 (Pn)

| 参数 | 说明 | 当前值 |
|------|------|--------|
| Pn001 | 每转脉冲数 | 10000 |
| Pn023 | 控制模式 | **3** (P-485 位置模式) |
| Pn025 | RS485 波特率 | 3 (115200) |
| Pn026 | RS485 从机地址 | 3 |

### Pn023 模式对照

| 值 | 模式 | 说明 |
|----|------|------|
| 0 | P-PUL | 脉冲+方向 |
| 1 | S-Io | IO控制 |
| 2 | S-Vr | 模拟量 |
| 3 | **P-485** | RS485 位置模式 ← 当前使用 |
| 4 | S-485 | RS485 速度模式 |
| 5 | t-485 | RS485 转矩模式 |

## 寄存器速查表 (P-485 位置模式)

### 状态/反馈

| 寄存器 | 类型 | 说明 |
|--------|------|------|
| 0x0064 | uint16 | 状态/故障码 |
| 0x0066+0x0067 | int32 | 编码器值 (当前圈内位置) |
| 0x0068+0x0069 | int32 | 圈数值 |
| 0x038B | uint16 | 到位信号: **0**=运动中, **1**=已到位 |

### 运动控制

| 寄存器 | 类型 | 说明 |
|--------|------|------|
| 0x0384 | uint16 | 使能/启停控制 |
| 0x0385 | uint16 | 位置触发: **0**=停止/就绪, **1**=启动 |
| 0x0386+0x0387 | int32 | 目标位置 (脉冲数) |
| 0x038C+0x038D | int32 | 速度 (脉冲/秒) |
| 0x0392+0x0393 | int32 | 加速度 (脉冲/秒²) |
| 0x0394+0x0395 | int32 | 减速度 (脉冲/秒²) |
| 0x0390 | uint16 | EEPROM 保存 |

> **注意**: 32 位寄存器分两个 16 位: **低字在前** (base_reg), **高字在后** (base_reg+1)
> 例: 速度 = 20000 = 0x00004E20 → 0x038C=0x4E20, 0x038D=0x0000

## 常用命令示例

以下示例中 `03` 为电机地址, CRC 计算方式: 多项式 0xA001, 初始值 0xFFFF, **HI-LO 字节序**。

### 1. 读当前位置 (编码器 + 圈数)

```
→ 03 03 00 66 00 02 25 F6    (读 0x0066, 2个寄存器)
← 03 03 04 XX XX XX XX CRCL CRCH

→ 03 03 00 68 00 02 44 35    (读 0x0068, 2个寄存器)
← 03 03 04 XX XX XX XX CRCL CRCH
```

### 2. 写速度 (0x038C, int32)

```
→ 03 10 03 8C 00 02 04 XX XX XX XX CRCL CRCH
                                  └─低字──┘└─高字──┘
← 03 10 03 8C 00 02 CRCL CRCH

示例: 速度=20000=0x00004E20
→ 03 10 03 8C 00 02 04 20 4E 00 00 CRCL CRCH
```

### 3. 写目标位置 (0x0386, int32)

```
→ 03 10 03 86 00 02 04 XX XX XX XX CRCL CRCH

示例: 位置=140000=0x000222E0
→ 03 10 03 86 00 02 04 E0 22 02 00 CRCL CRCH
```

### 4. 触发运动 (0x0385)

```
停止: → 03 06 03 85 00 00 99 85
启动: → 03 06 03 85 00 01 58 45
```

### 5. 查询到位状态 (0x038B)

```
→ 03 03 03 8B 00 01 F5 86
← 03 03 02 00 01 CRCL CRCH   (0x0001=已到位)
← 03 03 02 00 00 CRCL CRCH   (0x0000=运动中)
```

### 6. 查询状态/故障 (0x0064)

```
→ 03 03 00 64 00 01 C5 D5
← 03 03 02 00 XX CRCL CRCH
```

## 完整运动流程

```
1. 写速度      → 03 10 03 8C ... (Fun10, int32)
2. 写加速度    → 03 10 03 92 ... (Fun10, int32)
3. 写减速度    → 03 10 03 94 ... (Fun10, int32)
4. 写目标位置  → 03 10 03 86 ... (Fun10, int32)
5. 触发启动    → 03 06 03 85 00 01 (Fun06)
6. 轮询到位    → 03 03 03 8B ... (Fun03, 直到返回0x0001)
7. 停止触发    → 03 06 03 85 00 00 (Fun06)
```

## 手册例程: P-485 单寄存器写入 (全部用 Fun06)

> 以下来自说明书第 3.2 节，参数: **Pn001=10000**, **Pn026=3**
> 目标: 正转 100 圈 (1,000,000 脉冲)，速度 200,000 pps，加减速 500,000 pps²

### 参数计算

| 参数 | 目标值 | 十六进制 | 低字寄存器 | 高字寄存器 |
|------|--------|----------|------------|------------|
| 速度 | 200,000 pps | 0x00030D40 | 0x038C=0x0D40 | 0x038D=0x0003 |
| 加速度 | 500,000 pps² | 0x0007A120 | 0x0392=0xA120 | 0x0393=0x0007 |
| 减速度 | 500,000 pps² | 0x0007A120 | 0x0394=0xA120 | 0x0395=0x0007 |
| 位移 | 1,000,000 | 0x000F4240 | 0x0386=0x4240 | 0x0387=0x000F |

### 只用 Fun06 (单寄存器写，与说明书一致)

```
1.  写速度低字     → 03 06 03 8C 0D 40 4C E7
2.  写速度高字     → 03 06 03 8D 00 03 58 46
3.  写加速度低字   → 03 06 03 92 A1 20 51 C9
4.  写加速度高字   → 03 06 03 93 00 07 39 83
5.  写减速度低字   → 03 06 03 94 A1 20 B1 C8
6.  写减速度高字   → 03 06 03 95 00 07 D9 82
7.  写位置低字     → 03 06 03 86 42 40 58 D5
8.  写位置高字     → 03 06 03 87 00 0F 78 41
9.  触发=0 (就绪)  → 03 06 03 85 00 00 99 85
10. 触发=1 (启动)  → 03 06 03 85 00 01 58 45
11. 轮询到位状态   → 03 03 03 8B 00 01 F5 86
```

### 用 Fun10 (连续写，固件当前使用的方式)

```
1.  写速度   → 03 10 03 8C 00 02 04 0D 40 00 03 A7 AB
2.  写加速度 → 03 10 03 92 00 02 04 A1 20 00 07 07 A6
3.  写减速度 → 03 10 03 94 00 02 04 A1 20 00 07 87 8C
4.  写位置   → 03 10 03 86 00 02 04 42 40 00 0F 31 05
5.  触发=0   → 03 06 03 85 00 00 99 85
6.  触发=1   → 03 06 03 85 00 01 58 45
7.  读到位   → 03 03 03 8B 00 01 F5 86
```

> **Fun10 数据字节序**: 固件 `Send_Func10_Data` 中 32 位值按 [bits8-15, bits0-7, bits24-31, bits16-23] 排列，即每个 16 位字内部 HI-LO 字节序，低字在前高字在后。
